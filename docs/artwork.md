# Original artwork

`frontend/public/hero.png` was created with the built-in image generation tool for this project. The reference informed layout and colors; it was not used as a screenshot background. All controls are real React components. Demo video uses this illustration with scripted local synthetic speech.

Final generation prompt:

> Use case: illustration-story. Create an original very wide anime illustration banner for LinguaEcho, nostalgic early 2000s hand painted shoujo storybook aesthetic. Sunlit European lakeside village and castle in distance, cherry blossoms framing the upper corners, cream parchment and meadow green leaves, peach and burgundy accents. On the right half a friendly original brown-haired young adult woman with green eyes, burgundy hair ribbon, cream blouse, headphones around neck, leaning beside a small sleeping white cat. Left half mostly quiet pale sky and cream texture for overlaid website title. Delicate ink lines, watercolor texture, warm afternoon light. Landscape 3:1 composition. No text, no letters, no logos, no copyrighted characters. This is illustration artwork only, not a website screenshot.

This PNG is replaceable without changing application logic. Demo source text lives in `fixtures/script.json`; regeneration scripts are in `scripts/`.
