# Presentation script — under two minutes

**0:00–0:15:** Introduce the problem: understanding spoken media while keeping the original speaker. Show the responsive interface and original artwork.

**0:15–0:30:** Click **Explore the demo** and explain its visible label: scripted Japanese/English text, locally synthesized fixture voices, and no live AI call. Normal uploaded media uses OpenAI.

**0:30–0:55:** Select **Original → Translation** and Play. Let the first sentence finish; point out that video pauses during the translated voice and resumes afterward.

**0:55–1:15:** Switch to Translation Only, Original Only, then Audio only. Replay sentence three, favorite it, and mention Space and arrow-key shortcuts.

**1:15–1:35:** Search a phrase, copy a sentence, download translated SRT, and reopen the saved project from My Library.

**1:35–1:55:** Show language search and Settings. Mention translator persona, few-shot examples, validated JSON, and documented prompt revisions. Explain that live AI needs an API key with available quota; the offline demo remains usable.
